# ADR-0001: 商品詳細導線に React Router を採用する

- ステータス: 採用
- 日付: 2026-07-17

## 背景
商品一覧 `/` から `/product/:id` の詳細へ遷移し、一覧へ戻ったときに検索状態も保持する必要がある。

## 決定
`react-router-dom` を導入し、一覧と詳細をルートで分離する。検索キーワードは `q` クエリで管理する。

## 理由
URL だけで画面状態を表現でき、ブラウザの戻る操作と明示的な戻るリンクの両方で同じ状態を再現できるため。

## 却下した代替案
`window.history.pushState` を使う独自実装は依存追加を避けられるが、ルート解決・テスト・保守を自前で持つ必要があり見合わない。

## 影響
Node 20+/React 18 との互換条件を満たすランタイム依存が 1 つ増える。検索条件を含む共有可能な URL を提供できる。
